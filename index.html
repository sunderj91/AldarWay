How the system works — read this first

The sales platform has no database of your assets. File names ARE the wiring. Three files are joined by one token — the CamelCase RoomName — and one number, the image index. If any of the three spells a room differently, that room breaks.

The one rule

Artists never invent names. Humans deliver into a fixed intake template with friendly names; the deployment structure is generated by script and gated by this validator. Every project — single tower, multi tower, villa or mixed — uses the same grammar; only the unit-code prefix and the tower/villa backplate folders change.

Project root

project_[version]_[country]_[city]_[project-slug]/     e.g. project_1-0-1_uae_abu-dhabi_thecanopies
lowercase · "_" separates tokens · "-" replaces spaces inside a token · ASCII only · no spaces anywhere

Core folder structure (pick your project shape)


  
Folders that don't apply to a shape are simply absent — never empty, never renamed. image_360_property_variation/ holds type-level renders (re-used across units); image_360_property_unit/ holds unit-level renders with unique views. A project may use either or both.

Room dictionary (CamelCase — identical across images, camera CSV, floorplan CSV)

  

    MasterBedroomMasterBathroomBedroomBedroom1Bedroom2Bedroom3BathroomBathroom1Bathroom2PowderRoomKitchenLivingDiningFoyerCorridorLaundryMaidRoomMaidBathroomStudyBalconyLivingBalconyMasterBedroomBalconyMasterBedroomWardrobeFamilyRoomMajlisTerraceStorePantryDriverRoomGarageGardenRoof
    
    
      
  • First bedroom is the master: in 1-bed and 2-bed units the primary bedroom is MasterBedroom (its ensuite MasterBathroom); remaining bedrooms are Bedroom1, Bedroom2… with ensuites Bathroom1, Bathroom2. Studios use Bedroom.
    • 
      
  • No corridor sub-rooms: approach/passage shots belong to the room they lead to, numbered after the in-room shots — the lowest index is the landing image when a floorplan label is clicked, and it must be inside the room.
    • 
      
  • Foyer is mandatory: the tour\u2019s Enter button lands on the Foyer (or Entrance) camera \u2014 a unit without one opens on a random room. Foyer index 1 = the entry view.
    • 
      
  • Passage → Corridor, Common/guest toilet → Bathroom (or PowderRoom when the plan says so). Never LOUNDRY / COMMEN / free-spelling — the dictionary is closed; new rooms need sign-off.
    •

Alternative (heavier, zero-trust)

  
Skip human folder discipline entirely: a web upload portal per project where artists drag renders against a pre-created unit-type matrix (from the stacking plan). Names are assigned by the system at upload; nothing misnamed can enter. Same validator runs server-side on every upload. Recommended once volume crosses ~5 projects/quarter — until then the intake template + this validator gives 95% of the protection at 5% of the build cost.
